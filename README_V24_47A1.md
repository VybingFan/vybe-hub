# VYBE V24.47A1 — Shared Playlist Player + Song Detail

Rush friends-and-family refinement.

- Makes the shared playlist player more compact on mobile.
- Adds a click/tap detailed song view from the current artwork/title.
- Detailed view includes large artwork, subtle playback motion, song/artist information,
  progress, previous/play-next controls, and close action.
- Does not change audio URLs, playlist security, activity tracking, or playback authorization.

Tier direction:
- Expanded song presentation: Creator Plus, Creator Pro, Creator Studio.
- During founding/beta, the experience can remain enabled for testing.
- Custom profile themes are not included here; Pro/Studio theme work follows separately.
