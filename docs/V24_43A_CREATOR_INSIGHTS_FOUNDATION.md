# V24.43A Creator Insights Foundation

Combines the former Activity and Analytics navigation into one membership-aware Creator Insights workspace.

## Included

- One Audience > Insights navigation item; Connections remains separate.
- Overview, Playlists, and Engagement categories.
- Playlist opens, playback starts, unique visitors, followers, likes, saves, and comments.
- Complete playlist aggregates for the membership reporting period instead of totals derived from the latest 250 rows.
- Existing `/activity` links redirect to `/creator-analytics`.
- Existing Creator Pro CSV entitlement remains enforced.

## Intentionally deferred

Qualified plays, playback checkpoints, listening time, completion, retention, repeat listeners, traffic sources, and deeper audience segments require the next playback-event migration.
