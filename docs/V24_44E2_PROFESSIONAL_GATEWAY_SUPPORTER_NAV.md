# V24.44E2 — Professional Gateway + Supporter-First Navigation

Creates `/build-with-vybe` as a first-class professional VYBE homepage for creators, businesses and partners.

Navigation changes:
- removes the large Build on VYBE dropdown from the supporter-facing primary navigation;
- adds one `Build With VYBE` gateway inside More;
- removes the separate Creator Sign In button from the signed-out desktop header;
- keeps Supporter Sign In + Create Free Account as the main supporter auth actions;
- mobile receives the same supporter-first treatment.

The gateway gives creators the dominant professional story, businesses/partners a dedicated path, and retains Trust & Safety, Copyright & Content Use, Community Guidelines and Help as relevant resources for both creators and increasingly participatory supporters.

No Supabase migration. Existing Creator Studio, Business Portal and Operations access controls are unchanged.
