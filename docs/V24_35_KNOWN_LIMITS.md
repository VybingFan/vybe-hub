# V24.35 Known Limits

- Password validation and approved-listener email/token issuance require the follow-up access-grant UI/server function before those modes are production-ready.
- Client preview generation depends on browser AudioContext decoding support.
- Existing preview tracks without a `preview_audio_path` need their preview regenerated by replacing/re-uploading audio.
- Membership-only playback requires wiring to the final listener entitlement resolver.
- `nodownload` is a UI discouragement, not DRM.
