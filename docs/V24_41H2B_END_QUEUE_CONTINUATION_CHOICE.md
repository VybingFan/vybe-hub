# V24.41H2B End-of-Queue Continuation Choice

When the creator's eligible public queue ends, VYBE now asks the listener what should happen next instead of stopping without explanation.

The prompt supports replaying the current creator, stopping, or opening Discover. Similar-music and Top 50 choices are visibly marked as coming soon until VYBE has sufficient recommendation and chart data to produce truthful results.

Private, unlisted, membership-only, approved-listener, unavailable, and restricted-playback songs remain excluded from automatic public continuation.

No database migration or creator-content changes are included.
