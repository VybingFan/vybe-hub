# V24.42B2B Film Project Media & Private Review Foundation

## Included

- Assign Video Library items to a Film project.
- Media roles: trailer, clip, scene, rough cut, teaser, behind the scenes, and other.
- Explicit finished or unfinished state and creator version/context notes.
- Draft review briefs for creative review, rough cuts, scenes, festival review, and music matching.
- Film focus and ownership enforcement at the database.
- Project Media & Review Creator Studio page.
- Empty Video Library guidance with a direct Add Video action.
- Visible review title, purpose, and instruction labels.
- Attach controls remain disabled until a Video Library item exists.

## Security boundary

External YouTube, Vimeo, and similar provider URLs are not confidential delivery. Review briefs remain drafts and cannot be shared in this bundle. Film downloads remain locked.

Review sharing activates only after the existing secure-playlist system can authorize and render mixed video items with password verification, approved viewers, expiry, revocation, playback logging, and creator self-view exclusion.

## Test

1. Open Project Media & Review from the sidebar.
2. Attach a Video Library item to the test Film project.
3. Mark it unfinished and choose Scene or Rough Cut.
4. Refresh and confirm persistence.
5. Create a Music Matching review brief.
6. Confirm it displays `Draft · sharing locked`.
7. Confirm there is no share or download button.
