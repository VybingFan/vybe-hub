# VYBE V24.47B1R1 - Non-Music Play Preview Flow Repair

Repairs the rush non-music preview interaction.

Changes:
- Each Film / Video, Dance, and Podcasting preview now contains 3 questions.
- Correct answers show Next question instead of Try again.
- Wrong answers show the correct answer, explanation, Next question, and an optional retry.
- Adds question count, progress bar, score, final score screen, replay, and choose-another-preview actions.
- No database migration.
- No change to the existing published game-pack service or admin publishing flow.
